# 魔兽陪伴精灵

魔兽世界正式服与无限服的 Windows 桌面陪伴工具。游戏插件提供角色事实与规则结论，桌面负责记忆、对话、语音字幕、截图和本地档案。

文档更新：2026-11-08。以下版本对应本机当前开发与交付目录，不代表 GitHub 已同步发布。

| 组件 | 当前版本 |
| --- | --- |
| 桌面程序 | 2.27.1 |
| 正式服插件 `WoWMapCompanion` | 2.25.0 |
| 无限服插件 `WoWForeverCompanion` | 1.21.0 |
| 屏幕桥接 | 2.25.0 |

## 开始使用

当前安装版为 [2.27.1 Windows x64 安装程序](WoWCompanion-2.27.1-windows-x64-setup.exe)。复制到另一台电脑后双击，选择安装目录，完成后从桌面或开始菜单打开“魔兽陪伴精灵”。

1. 从系统托盘正常退出旧版精灵。
2. 双击本目录的 [Start-WoWCompanion.cmd](Start-WoWCompanion.cmd)。
3. 在设置中选择聊天服务、模型与角色形象。语音、听觉和视觉服务按需配置。
4. 打开“魔兽世界正式服”或“魔兽世界：无限”，启用对应陪伴连接。
5. 更新配套插件后，完整重启游戏并登录角色。保持传输码可见，再检查采集区域。

在其他电脑使用时，运行2.27.1安装程序。安装包自带桌面运行环境和 Python，无需另装 Node.js、pnpm 或 Python。新电脑在设置中填写自己的模型服务配置，并选择游戏目录。

云端模型需要各自的服务凭据和可用额度。游戏数据码解码不需要视觉模型，也不需要 CurseForge API Key。

## 2.27.0 桌宠动画

角色显示采用 dsh-pet 的透明 WebM 动画，内置本地项目的蓝发小女仆及114段动作。右键宠物可以睡觉、唤醒、转身、随机动作、打开聊天或形象设置。点击回应、拖动、思考、情绪和语音播报也会切换动画。

在“设置 → 桌宠形象”预览、选择动画包和设置50–200%的大小。自定义包使用 `pack.json` 与清单中的 WebM 文件，导入后复制到个人资料目录的 `dsh-pet-packs`。格式和限额见[完整说明](wow-companion-implementation.html#dsh-pet-2-27)。

桌面、独立工作区和设置预览共用所选动画包。聊天、语音字幕、游戏连接、档案和关系记忆继续使用原个人资料。旧形象的文件与引用保留在档案中，桌面角色加载由新动画包负责。

## 2.26.0 安装与 Token 统计

独立的[数据中台](WoWCompanionDataHub/README.md)提供 Docker 部署、管理员登录、安装数量、5 分钟／24 小时活跃安装、Token 汇总、UTC 每日趋势、版本分布和 CSV 导出。数据保存到服务器 SQLite 持久卷。

客户端首次运行显示告知，默认勾选开启；点击“继续”后才收集和发送，可以在“设置 → 安装与用量统计”关闭。关闭或稍后处理告知期间不会收集。服务器尚未部署时地址为空，不会向外发送。部署步骤见[完整说明](WoWCompanionDataHub/README.md)。

登记只包含随机安装 ID、用于上报认证的随机 secret、软件版本和平台。其后每 300 秒上传累计用量和心跳，断网保留计数、重试去重。不上传聊天、截图、语音、角色信息、模型服务凭据或模型名称。普通备份不携带安装统计身份，避免迁移到另一台电脑后复用同一个安装 ID。

安装数量不是自然人数。Token 只统计模型接口实际提供的字段，并显示缺失用量记录及字段覆盖率；一条 SDK 生成可能包含多轮工具请求，返回用量可能不完整。TTS／ASR 当前没有统一 Token 返回，未纳入。不能作为完整账单或扣费依据。每天的增量按服务器 UTC 接收日统计，离线补报记在接收日。

## 2.25.0 的功能分工

| 功能 | 插件负责 | 桌面负责 |
| --- | --- | --- |
| 角色状态 | 名称、等级、职业、专精、阵营、种族、地图、坐标及生死战斗状态 | 当前角色称呼、对话资料与档案展示 |
| 装备 | 新装备读取、比较结论、属性差值、游戏内确认和换装复核 | 祝贺、属性取舍说明与字幕，不重复计算升级判定 |
| 任务 | 可交付、实际交付、等级风险与真实升级后的任务候选 | 时效、回执、自然语言表达与播报安排 |
| 金币和等级 | 游戏观测及已保存历史 | 跨角色汇总、现实升级耗时与离线档案 |
| 背包与银行 | 当前公开可读容器、数量、属性与提示摘要 | SQLite 保存、搜索、筛选与聊天资料 |
| 陪伴 | 提供可信事件和真实脱战次数 | 关系记忆、自然闲聊、地图逸闻、语音、字幕和截图对话 |

换装只在游戏内点击确认。桌面气泡不再提供第二组“好／不用”；播报结束后保留 3 秒。

升级、生死、日历和组队增益等固定通知使用 12 语言模板，不调用聊天模型。语音未配置或播放失败时显示 8 秒文字。全局静音、零音量和免打扰规则继续生效。

普通闲聊、地图逸闻、任务自然表达和截图对话仍使用对应模型与人设。记忆及关系成长规则保留。

## 设置入口

- **对应游戏版本**：连接状态、当前角色与陪伴偏好。
- **对应游戏版本 → 角色档案**：金币、等级、装备及背包银行记录，默认折叠，展开后加载详情。
- **对应游戏版本 → 连接诊断与采集设置**：传输码截取与连接排查。
- **对应游戏版本 → 事件与演示**：事件记录与测试入口。
- **魔兽工具**：插件中心、启动配置、任务、专业、配装、资料库、数据包、安装更新与备份等附加功能。原页面地址继续可用。
- **闲聊设置／记忆与关系／游戏截图辅助**：设置主动互动、记忆和看图功能。

进入工具入口不会自动查询全部工具。数据包更新监测在首次实际使用该工具后启动，持续到退出程序。

## 数据与边界

默认个人资料目录为 `%USERPROFILE%\.airi-wow-companion`。设置了 `APP_USER_DATA_PATH` 时，使用指定目录。

物品数据库为该目录下的 `wow-companion-items.sqlite`。通过软件备份导出逻辑记录，不单独复制运行中的 SQLite 主文件。

银行必须在游戏内打开后才能读取。关闭银行后保留带时间的旧记录；未知或不完整页面不会清空旧物品。专业物品包含材料、配方、工具装备及制作成品候选，不能确认的制作来源单独标记。

金币记录的是钱包流入和流出，转账也包含在内。现实升级耗时与插件累计在线时间采用不同口径，不互相替代。怀旧服目前提供知识及插件管理入口，不包含本项目的实时遥测插件。

## 程序包保留规则

桌面便携包、桌面构建目录、正式服插件包、无限服插件包和源码压缩包各自保留最近 5 个版本。不足 5 个时全部保留，配套校验文件随对应包处理。

截至 2026-11-04，桌面保留 `2.25.0`、`2.24.0`、`2.23.2`、`2.23.1`、`2.23.0`。源码目录、个人配置、数据库和备份不属于程序包清理对象。这是维护规则，不代表已配置定时清理。

## 源码目录与开发

本机使用同级目录 `I:\GameTools\WOWAddons` 与 `I:\GameTools\airi`。本目录包含插件、桥接、启动器和说明，桌面源码位于同级 `airi`。

在桌面源码根目录使用仓库指定的 Node.js 和 pnpm。现有依赖环境的检查命令：

```powershell
$env:pnpm_config_verify_deps_before_run='warn'
pnpm -F @proj-airi/i18n build
pnpm -F @proj-airi/stage-tamagotchi typecheck
pnpm -F @proj-airi/stage-tamagotchi build
```

开发模式的屏幕桥接需要 Python 3.10 或更新版本。普通便携版用户使用包内运行环境。
