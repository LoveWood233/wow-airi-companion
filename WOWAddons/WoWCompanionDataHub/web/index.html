如何解读这些数据

  • 安装数是首次运行登记数，不等同真实用户数；重装或更换配置目录可能产生新登记。
  • 数据由客户端自报，可能被伪造。仅用于趋势观察，不是计费账单或审计凭据。
  • 仅累计服务商实际返回的 Token 数字；缺失字段保持未知，不估算、不补零。未返回 Token 的 TTS/ASR 不纳入。
  • 一次用量记录代表一次 SDK 生成，可能包含多个 HTTP 工具轮次；有用量报告不代表每一轮都完整。
