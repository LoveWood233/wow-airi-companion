# 魔兽世界：无限功能支持与启用记录

本文记录游戏插件、桥接和桌面端对《魔兽世界：无限》的支持范围，以及本次启用时实际核实的结果。为保护隐私，文档不保存角色名、GUID、账号标识或密钥。

## 如何理解支持状态

| 状态 | 含义 |
| --- | --- |
| 代码已适配 | 已有无限服分支或可复用的公共实现；不代表本次已在真实客户端完成验收。 |
| 本次实机已验证 | 本次已观察到真实游戏、桥接或桌面状态的对应证据。仅覆盖明确列出的项目。 |
| 条件支持 | 实现存在，但依赖客户端可读数据、额外配置、资料来源或特定场景；条件不满足时应显示未知或不可用。 |
| 未适配 | 当前没有相应无限服实现或可靠资料，不能套用正式服、怀旧服结果。 |
