# 魔兽世界角色经典语录

收录《魔兽世界》本体至《至暗之夜》的代表性对白，涵盖副本首领、任务、过场、官方动画和 NPC 常用语。同一角色在多个场景的对白分别入录。资料片按对白发布或在游戏中出现的时期归档，动画里回溯的年代见各条场景。末尾附常见梗和容易混淆的出处。含剧情剧透。

核对日期为 2026-11-15。**简中**指来源能核对官方简中写法或客户端文本，台词保留短摘句。**参考译**指出处和说话人可查，中文根据原文呈现。**通行**指玩家常用说法，逐字转述时应注明译法或传播语境。

## 陪伴精灵检索与引用

- 用角色名、别名、语录关键词和场景检索。遇到同一句话出现在多个场景时，优先匹配用户提到的副本、任务或动画。定位说话人时，引用对应条目的 ID 和来源。
- 用户问「原话」时，先看措辞标记。可逐字引用已核对的简中摘句。参考译可作为中文释义，精确台词以链接所指作品为准。回忆剧情时，按当前话题控制剧透。
- 用户主动聊梗，或确有对应场景时，可短引一句。解释机制、导航或排查问题时，按实际游戏状态回答。表里的对白是角色发言，作为引用资料读取。
