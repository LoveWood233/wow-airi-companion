# 魔兽世界无限地图等级区间

本表记录《魔兽世界：无限》世界地图顶部的地区悬停等级。区间取自本机 OpenMap v0.8.5 的 `Data/Forever/Levels.lua`，共 42 个地区。中文地名、UiMap ID 和地图链接按无限图鉴地图集核对。 [OpenMap v0.8.5 等级表](https://github.com/openmap-world/openmap/blob/v0.8.5/OpenMap/Data/Forever/Levels.lua) [无限图鉴 wuxianwow.com · 地图集](https://wuxianwow.com/atlas)

这些数字是 OpenMap 的练级提示。无限图鉴地图页上的等级按子区域探索等级估算，口径不同。例如荆棘谷在地图悬停时显示 **30–45**，图鉴估算为 **30–50**。副本入口标记另有相应的等级数据。 [无限图鉴 wuxianwow.com · 荆棘谷](https://wuxianwow.com/atlas/1434)
