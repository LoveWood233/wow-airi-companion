魔兽陪伴精灵 2.27.1 — Windows x64 安装版
更新日期：2026-11-08

2.27.0 新增 DSH Pet 动画桌宠
1. 双击 WoWCompanion-2.27.1-windows-x64-setup.exe，按向导安装。从桌面或开始菜单打开“魔兽陪伴精灵”。
2. 主桌面、工作区与设置预览统一使用透明WebM动画。默认内置蓝发小女仆，114段素材约57.8 MB。
3. 左键点按触发回应，按住拖动移动窗口。右键菜单可打开聊天、点播随机动作、睡觉、醒来或翻转朝向。
4. 设置 → 桌宠形象，可切换宠物、预览动作并调节50%～200%尺寸。已打开的显示窗口会同步形象与尺寸设置。
5. 动画结合思考、说话及情绪切换。聊天模型、语音字幕、魔兽事件、角色档案、记忆与游戏连接继续从现有设置使用。
6. 旧模型资料保存在个人档案中。当前通过新动画包管理形象，需要自行准备透明WebM素材。
7. 导入时选择含规范pack.json及其声明WebM文件的目录。每包最多256个媒体文件，单文件最多32 MiB，总量最多512 MiB。
8. 软件验证清单和资源路径，将允许的文件复制到当前个人资料目录的dsh-pet-packs。重启后可继续选择使用。
9. 动画包支持待机、转向、点击、拖拽、随机动作分类及同套的睡眠开始/循环/醒来三段。可先在设置页预览。
10. dsh-pet动画素材与播放机制采用MIT许可证，Copyright (c) 2026 PC2005-cloud，完整许可随内置动画包提供。

以下保留2.26及更早版本的功能说明与便携包操作记录。当前安装、形象操作以本节为准。

2.26.0 新增：安装与 Token 用量统计
1. 首次启动或升级后显示统计告知，选项默认开启，只有点击“继续”才开始收集。可取消勾选或选“关闭统计”；“稍后”与 Escape 不会开启。
2. 设置 → 安装与用量统计：填写管理员提供的HTTPS服务根地址，例如 https://stats.example.com。地址留空不会联网发送，不需要管理员密钥或模型API Key。
3. 启用且地址有效后，登记或恢复连接时发送检查点，运行期间固定每300秒（5分钟）上传累计计数。本页显示本地累计、覆盖情况、最后成功时间与错误。
4. 仅发送随机安装标识、版本、平台及累计用量。不发送聊天、角色、截图、音频、服务商名、模型名或API Key。安装认证凭据由客户端自行生成。
5. 安装数不等于人数。清空、重建个人资料会产生新标识。不要将一份个人资料复制给不同用户，否则共用安装身份。
6. 用量记录数是SDK生成记录数，不是HTTP请求数。只累计大模型实际返回的Token；缺失字段为未知，各字段有独立覆盖记录数，不按字数估算。
7. 包含聊天、视觉、闲聊、任务等大模型用量。TTS/ASR的字符与时长费用未统计，不是服务商账单或计费依据。
8. 已启用时离线也会本地累计，恢复联网后补报。观察ID与递增检查点去重，服务端只累计新检查点增量，重试不重复加Token。
9. 在本页关闭收集与上报并保存即可停止。此前已上报的统计仍保留在服务器。
10. 桌面2.26.0；配套正式服插件与桥接仍为2.25.0，无限服插件仍为1.21.0。下面的2.25精简功能继续保留。

服务器部署由软件发布者或管理员完成
另行提供 WoWCompanionDataHub-1.0.0-docker-source.zip，服务端版本1.0.0，不需要安装桌面程序或游戏。
在服务器安装Docker Engine、Compose及Python 3，解压后进入包含compose.yaml的目录：
  python3 setup.py
  docker compose config
  docker compose up -d --build
  docker compose ps
setup.py生成.env与secrets/admin-key.txt，不打印或覆盖已有密钥。管理页面初次可通过服务器本机 http://127.0.0.1:8080 访问；远程查看可使用SSH隧道。
管理员密钥只用于管理页面，绝不能写入客户端、镜像、公开仓库或聊天。
对外使用前，按服务器包README配置自己的域名和HTTPS反向代理，设置.env中的DATAHUB_ALLOWED_HOSTS、DATAHUB_PUBLIC_ORIGIN及Secure Cookie。端口保持绑定宿主127.0.0.1。
客户端只需设置公开HTTPS根地址。发布者也可先修改源码 apps/stage-tamagotchi/resources/wow-statistics.json 的 endpoint，再重新构建发行包；每位用户仍需点击告知中的继续。
已通过服务器23项、客户端到真实本机HTTP/SQLite服务集成10项、客户端协议与浏览器回归50项。本机没有Docker，未执行容器启动验证；最终构建和归档校验见交付记录。

2.25.0 历史精简功能（继续保留）
1. 装备与任务规则由插件提供结论，桌面不再重复判定。
2. 换装只在游戏内确认，桌面不再显示第二组“好／不用”。
3. 升级、生死、日历和组队增益使用固定模板与统一语音/字幕，不调用聊天模型。
4. 无语音模型或语音失败时显示8秒文字；全局静音或零音量时不主动提醒。
5. 设置页角色档案、诊断和事件默认折叠；工具集中在“设置 → 魔兽工具”。
6. 记忆、关系、自然聊天、地图逸闻、截图及SQLite保留，历史资料不删除。
7. 配套组件需同时更新。正常退出精灵、更新插件后，重启桌面和游戏。

开始使用
1. 将整个ZIP解压到新电脑的普通本地文件夹。
2. 打开解压目录，双击 Start-WoWCompanion.cmd 或 wow-companion.exe。
3. 保留 resources 和其他同级文件。不能只复制EXE，也不能在压缩包预览中启动。
4. 发行包自带桌面运行环境和Python，无需另装Node.js、pnpm或Python。
5. 新电脑没有你的私人密钥与聊天记录。请在设置中配置聊天服务与模型，再配置需要的语音、视觉和听觉服务。
6. 在对应游戏版本的使用向导中选择客户端目录并安装配套插件。也可从AddOns文件夹手动复制。
7. 完整重启游戏，启用插件并进入角色。打开对应版本的陪伴连接，在新电脑重新校准数据传输码。
8. 更多步骤见同目录“使用说明.html”。

正式服插件：AddOns/WoWMapCompanion
无限服插件：AddOns/WoWForeverCompanion
手动复制目标：对应版本客户端的 Interface/AddOns/ 目录。
桥接由桌面程序自动管理，无需另外启动。
配套桥接与正式服插件版本为2.25.0，无限服插件为1.21.0。

2.24.0 新增：背包与银行物品 SQLite 仓库
1. 更新配套插件，完整重新登录角色。保持64×64数据码可见，打开银行并等待扫描和传输。
2. 设置 → 对应魔兽世界版本 → 角色档案 → 背包与银行物品仓库（角色物品档案），点击“查看物品”。
3. 按角色、背包/角色银行/共享银行、装备/专业物品筛选，搜索名称或物品ID，分页展开属性词条。
4. 专业物品包括宝石、材料、配方及专业工具装备（3/5/7/9/19），也包含制作成品候选（消耗品0/背包1/强化8）。候选单独标记“来源未确认”，可单筛；药水、食物、背包或附魔也可来自掉落/购买，不能认定实际制作来源。武器护甲仍按装备查看。全部可读物品原始记录也保存。
5. 未打开银行显示“未扫描”。旧银行数据保留原日期，未知或不完整页面保留旧行并标“当前未确认”；仅完整可信页面可确认空格并清旧行。
6. 34格混合容器跨语言模拟为83片、约55.75秒，首次多页银行可需数分钟。遮挡或重传会更慢。
7. 仓库装备提示最多4行×128字节，非穿戴物品2行×96字节，属性最多12项。裁剪会明确标记，不能当成完整词条；穿戴和新获取装备的独立详情规则不变。
8. 本地路径：%USERPROFILE%\.airi-wow-companion\wow-companion-items.sqlite，自定义APP_USER_DATA_PATH时跟随该目录。
9. 软件备份通过物品逻辑记录恢复到SQLite，不复制运行中的数据库/WAL。“删除所有数据”会清空数据库，连接开启时可再次自动采集。
10. 物品页只查询SQLite，不发送反向游戏操作。本次自动化和模拟结果不能代替真实游戏、无限客户端或付费模型验收。

2.23.1 功能延续：长期记忆容量与提示
1. 下次开机后，先从托盘正常退出旧版，再使用原Start-WoWCompanion.cmd启动新版。
2. 打开“设置 → 记忆与关系”，查看已使用条数并修改长期记忆容量。
3. 每位精灵默认1000条，可设100～100000的整数。长期偏好与收藏去重后共同计数。
4. 容量满时停止新增长期偏好与收藏，普通游戏记录与聊天继续。不会自动删除长期记忆。
5. 可手动忘记条目、取消非偏好条目的收藏来腾出位置，也可直接提高容量。调低上限不删除现有内容。
6. 未带入本轮上下文的相关记忆仍在本地。上下文提示与容量提示按每位精灵、每种类型每天最多一次，重启不重播。
7. 提示在真实用户提问后等待空闲；已知在战斗时，须等脱战稳定10秒。不会消耗普通闲聊的时间或脱战进度。
8. 配置语音且未静音时使用语音与字幕，否则只显示文字气泡。不调用聊天模型，实际语音情绪取决于TTS服务。
9. 本轮记忆预算最多6条，含最多2条偏好、1条当前目标，每条文字最多280字，装备使用最多6项属性等摘要。这不是模型真实token上限检测。
10. 新功能最终构建与验收结果见本次交付记录。实际游戏与语音服务请按“使用说明.html”核对。

默认个人资料位置
%USERPROFILE%\.airi-wow-companion
程序目录与个人资料目录分开。移动程序目录不等于迁移个人资料。
如果自行设置了 APP_USER_DATA_PATH，以该路径为准。

更新与个人迁移
先从系统托盘正常退出，再操作文件。
更新软件时，将新版本完整解压到新目录，保留原个人资料。
迁移个人资料前，先退出两台电脑的程序并备份两边原目录。
资料中含凭据和账号记录，只用于自己的电脑间迁移，不要公开分发。
迁移后重新检查游戏路径、模型服务、音频与传输码校准。

角色形象
包内有Hiyori Pro/Free与AvatarSample_A/B预设。
个人希尔瓦娜斯模型、参考音频和自定义音色不随发行包自动复制。
需要时自行导入完整模型，并重新配置声音。
内置运行环境和外观资源不等于离线大模型。云端模型需要联网和可用额度。

故障检查
找不到Python：重新完整解压2.26.0发行包。开发模式另需Python 3.10+与正确PATH。
聊天无声：先检查语音服务、模型、音色和静音状态，再使用语音试听。
游戏无数据：检查插件、游戏版本、角色在线状态、传输码可见性和新电脑校准。
无法识图：配置视觉模型并开启游戏截图辅助。纯文本聊天模型需开启视觉“用于聊天”。
