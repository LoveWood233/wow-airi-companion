NEW / EQUIPMENT PROMPT

新装备升级提醒与选择

正式服插件 2.6.0、无限服插件 1.3.0、桥接与 AIRI 二开 2.6.0。按你选择的方案，最终换装仍在游戏内点击确认。

COMPARE

由游戏插件筛选

新装备资料完整、可以使用，且装等严格高于目标槽或目标槽为空时，生成候选。比较的是装等，不等于伤害或治疗收益一定提高；套装、特效、附魔和属性搭配需自行核对。

SPEAK / TEXT

语音可用就朗读

AIRI 直接朗读固定提示，不调用聊天大模型。无语音配置、静音或合成失败时，保留文字气泡。已有聊天或播报时等待其结束，候选失效则关闭。

CHOOSE

播完后选择

语音结束后才出现“好”“不用”，并开始 10 秒选择计时。纯文字提示立即显示选项。“不用”或超时关闭桌面气泡；“好”提示你在游戏内点击“确认换装”。

桌面选择与游戏确认：AIRI 不向游戏发送按键。气泡里的“好”不会直接换装，也不会跳过绑定等原生确认。气泡里的“不用”或超时只关闭桌面提示，不关闭游戏弹窗；没有游戏内确认就不会换装。游戏候选自创建起最多有效 120 秒，过期自动取消。

  1. 本机正式服插件更新后，在游戏聊天框执行 /reload；正常退出 AIRI，再双击 Start-WoWCompanion.cmd 加载新版桌面和桥接。如果当前使用手动运行的旧桥接，请先通过其停止脚本正常停止，再启动 AIRI。无限服开放后，将 新版无限插件 解压放入对应客户端 AddOns 目录。
  2. 保持传输码可见，确认 AIRI 对应版本的陪伴连接已开启、角色显示在线。插件换装提示默认开启；正式服可执行 /wowc equip on，无限服执行 /wowf equip on。
  3. 正常获得一件可使用、资料完整且装等更高的新装备。初次登录或重载时已有装备不算新增；同一实例卖出再回购通常会被去重，不适合作为新装备测试。
  4. 配置语音后，确认气泡随提示出现，语音播完再显示“好”“不用”。未配置语音时，确认立即显示文字及选项；无需配置聊天模型。
  5. 点击“不用”，或等待 10 秒不操作，气泡应关闭。再次测试时需另一条新的装备候选，重复传输不会反复提示。
  6. 点击“好”后，回游戏核对候选物品，点击游戏弹窗的“确认换装”。若出现游戏原生绑定、退款或交易确认，由你手动处理。只有插件核对穿戴槽中已是指定装备，才报告换装成功。

NEW / SPEECH CAPTIONS

角色旁显示语音字幕

PLAY

随实际语音显示

REPLACE

连续播报更新字幕

新的语音开始时显示新字幕，并取消旧的隐藏计时。旧回应延后结束时，不会清掉新字幕。

怎样使用与验收

角色作出回应

把确认的升级事实交给 AIRI 角色，使用已配置的模型与语音表达祝贺。

本机内存与传输：WoW Lua 无法直接写入供外部软件访问的共享内存。本版由插件显示编码网格，AIRI 管理的 Python 子进程解码后将状态保存在本机内存，通过本机 HTTP 交给 AIRI。
集成的含义：正常使用只启动 AIRI。桥接仍是隐藏的 Python 子进程，没有改为纯 JavaScript，也没有附带 Python 解释器。源码目录中 airi 与 WOWAddons 并列；安装包通过 extraResources 包含桥接脚本。
传输与 AI 分工：等级判断、校验和去重由代码完成。无需让视觉大模型反复识别数字；AI 负责收到事实后的表达。

几个重要的状态处理

  • 第一次连接：记录当前等级，不把已有等级当作刚刚升级。
  • 画面停更：超过 5 秒无新心跳，状态过期，不产生新的陪伴提醒。
  • 重载或换角色：更换基线，避免跨角色比较等级。
  • 战斗期间：继续更新信息，按免打扰设置控制主动回应。
  • 退出演示：清空演示基线，等待真实网格。
  • 桥接重启：用服务实例标识重置事件游标，不重播旧记录。
  • 进程退出：AIRI 只停止自己创建的桥接。父进程管道关闭也会让子进程退出，防止 AIRI 崩溃后遗留后台采集。
03B / GOLD LEDGER

账号金币怎样统计

以铜币为最小单位：1 金 = 100 银 = 10,000 铜。界面显示金、银、铜，不使用浮点小数累计。

先赚后花，分别入账

插件首次读取已有 100 金，只显示为余额。之后获得 3 金、花掉 2 金，即使两次变化都发生在一次桌面采集之前，累计流入仍是 3 金，流出是 2 金，净变化是 +1 金。

插件保留累计数，AIRI 只加入尚未记过的差额。AIRI 首次连接会导入插件已有累计收支。关闭 AIRI 后继续游玩，只要插件仍在采集且计数未丢失，下次连接会补上这段累计变化。

账号与余额的范围

同一账号 SavedVariables 下的角色会归为一组。你可以把自动标识改备注为“主账号”“小号账号”。这个功能不读取战网邮箱、密码或登录信息。

已知余额合计只包含本机观察过的角色，取各自最后一次余额。未登录角色、战团银行和公会银行的余额不在其中。

理解收入与消耗：统计的是角色钱包流入和流出，包含邮件、交易、修理、购买和银行存取。自己的角色之间转账会分别出现流出和流入；它们不等于纯收益或物品购买分类。此次不按日拆分，也不推断交易原因。
保留数据：不要删除插件 SavedVariables 或 AIRI 本地账本。清空插件保存文件会产生新的账号标识；把该文件复制给不同账号会复制标识。游戏异常退出前尚未保存的变化，以及插件未运行时的变化，无法完整追回。若恢复旧 SavedVariables 导致同一计数段的累计数回退，桌面会拒绝该角色的回退记录，直到收入和支出都追上已保存数值；此时账号汇总的最近采集时间不会更新，也不会自动补账。

03 · 必做 · 需要实际分辨率和显示器布局

让桌面捕获区域准确对齐游戏网格

缩小传输码：游戏内输入 /wowc cell 1，桥接页“每格像素”同步设为 1，即可缩至 64 × 64 物理像素。当前插件已修正屏幕分辨率和 UI 缩放导致的额外放大；首次更新旧版后需 /reload。主屏无边框、插件位置为 (8,8) 时，桥接填写 X=8、Y=8。窗口模式需加上客户区偏移；如单像素受到缩放或 HDR 干扰，可将两端都改回每格 2 像素。

  1. 第一次校准建议把 WoW 放在主显示器、无边框窗口模式，游戏画面保持可见。把 AIRI、浏览器和其他窗口移开网格所在区域，避免截图采到它们。
  2. 在游戏里运行 /wowc status 记下位置和每格尺寸。默认位置为游戏客户区左上 (8, 8)，每格 2 像素，总大小 128 × 128。
  3. 打开本机桥接页。主屏无边框且游戏客户区原点为 (0, 0) 时，填写屏幕 X=8、屏幕 Y=8、每格像素=2、轮询毫秒=500，点击“保存校准”。若页面显示“恢复采集”，再点击它恢复采集。
  4. 点击刷新预览。预览应恰好包含完整的 64×64 黑白格：没有标题栏、边框、背景，也没有切掉边缘。预览是点击时取得的截图，调整后要再次点击。
  5. 窗口模式或副屏上，填写的是桌面物理坐标，不能直接照抄插件坐标。计算方式：桌面采集 X/Y = 游戏客户区在桌面上的物理起点 + 插件 X/Y。例如客户区起点为 (200, 120)，插件为 (8, 8)，则填 (208, 128)。左侧/上方副屏可能使用负坐标。
  6. 也可以在 AIRI“魔兽世界正式服 → 屏幕位置校准”中填写同样数值并点击应用校准。截图预览在本机桥接网页中查看。两边编辑的是同一份桥接配置，选一处修改即可。

网格模糊、CRC 失败或一直等待：先核对坐标、遮挡和两端每格尺寸。如果网格边缘混入灰色或游戏背景色，进入游戏系统 → 图形，先切到窗口模式并应用，再切回全屏（窗口化）并应用，使用显示器原生分辨率；随后输入 /reload 重建游戏布局，再重新校准并刷新预览。游戏报告分辨率与 Windows 实际客户区不一致时，整幅画面会被再次拉伸；本机曾为 2560×1440 与 2576×1460，重新应用显示模式并重载后恢复一致，64×64 网格成功实时读取。若仍失败，检查 UI/Windows 缩放及 HDR，或将两端都恢复为每格 2 像素。不要只在一端改尺寸，也不要仅靠放宽校验阈值掩盖缩放问题。

本机当前校准：已保存 X=8、Y=32、每格像素=1，64×64 网格已持续读取真实等级 90、银月城及递增心跳。这是当前电脑和布局的实测值；移动网格、切换显示器或改变窗口位置后仍需重新校准。

成功标志：桥接页显示“真实游戏 · 已连接”，AIRI 显示“真实角色在线”，姓名、等级、地图与游戏一致，连续观察约 10 秒仍保持在线。状态不能是“演示数据”或“上次已知状态”。

04 · 文字陪伴必做 · 服务选择和凭据由你提供

配置对话服务，并真正选中一个模型

  1. 先进入 设置 → AIRI 角色卡，确认标有“当前使用中”的陪玩角色。然后确定你要使用、且已经可用的对话服务。云服务需要你自己的账户/访问凭据；本机模型服务需要你先启动服务并加载模型。本轮没有替你开通账号或选择付费套餐。
  2. 首次欢迎页可点配置您自己的 AI 服务来源；已有角色窗口则进入设置 → 服务来源 → 聊天，选择与你的服务一致的提供方。
  3. 按该提供方页面填写 API Key、服务地址等必填项；本机服务按页面要求填写地址。服务地址和模型标识以你所用服务的实际配置为准，不要随意增删路径。凭据直接填在 AIRI 中，不需要发给我。按页面完成验证，看到“配置验证成功”或相关检查项“通过”后再继续。
  4. 进入设置 → 机体模块 → 意识，选择刚配置的服务来源，再选择一个实际可用的对话模型。若提供方不支持列出模型，在页面提供的“模型名字”栏填写准确模型 ID，并核对“当前模型”显示正确。仅填写 Key、没有选模型，仍然无法回应。
  5. 回到角色主窗口，打开聊天，输入“请用中文简单问候我。”，确认能收到正常文字回复。再在真实角色在线时问“我现在多少级，在哪张地图？”，核对回答与陪伴页一致。

切换角色卡后要复核：角色卡可以保存独立的对话/声音选择，显式配置会覆盖继承值。进入 设置 → AIRI 角色卡 → 当前角色 → 卡片编辑 → 模块，检查“聊天”和“语音”；需要统一配置时选择“继承全局设置”，需要独立配置时明确指定提供方、模型和声线，再点“保存更改”。换卡后重新核对“意识”和“发声”。

成功标志：普通聊天能回复中文，陪伴页不再提示“请选择对话服务和模型”。普通聊天未通过前，不必反复触发游戏升级来排查。

05 · 语音陪伴必做；麦克风输入可选

先让角色能说话，再按需开启听觉

  1. 配置语音输出：进入 设置 → 服务来源 → 语音合成，配置你使用的 TTS 服务。对话模型可用不代表语音合成也已配置，这通常是两个独立设置。
  2. 进入 设置 → 机体模块 → 发声，选择语音服务、该服务支持的模型和声线；若服务需要手填声线 ID，填写其实际 ID。不要选择“无／不使用语音合成”。声线区域可能显示英文 Voice Configuration 或 Current voice，更换语音服务或模型后要重新核对声线。
  3. 在发声页下方实验平台输入“欢迎回到艾泽拉斯，我们继续冒险吧。”，点击测试声音，播放生成的音频。确认中文发音和音量正常。
  4. 回到 AIRI 主窗口，确保扬声器没有静音；检查 Windows 音量混合器中 AIRI/Electron 的音量及当前耳机/扬声器。再发一条普通聊天，确认同时有文字和声音。
  5. 可选语音输入：如果希望直接对精灵说话，先在 设置 → 服务来源 → 语音识别 配置 STT 服务，再进入 设置 → 机体模块 → 听觉 → 语音识别 选择服务、模型和麦克风。在“听觉测试面板”点击开始监听，由你允许需要的麦克风权限，说一句短句，检查转写文字；结束后点击“停止监听”。
  6. 听觉测试通过后，回到“听觉”页开启麦克风，选择持续聆听、按住说话或唤醒词方式，再使用主窗口“打开麦克风”。若“自动发送”关闭，需要手动发送转写稿；选择唤醒词方式时，要先配置并说出唤醒词。只需要精灵播报时，可以不配置听觉，也不必打开麦克风。

成功标志：发声测试和普通聊天都能听见声音。若还需要语音输入，说话能形成准确文字并进入对话；仅听见声音不代表麦克风链路已通过。

06 · 建议先做 · 不用等待真实升级

用演示分别验收数据、文字回应与语音

  1. 进入 设置 → 魔兽世界正式服，开启“开启陪伴”“升级时祝贺”“进入新区域时回应”“死亡后安慰”“复活后鼓励”；关闭“游戏提醒静音”，点击“保存陪伴偏好”。
  2. 若只验证数据，不必开启“允许角色回应演示事件”。若要验收 AI 文字/语音，先完成第 4～5 步，再明确打开允许角色回应演示事件并点击保存陪伴偏好。此时演示回应会使用你配置的模型和语音服务，按该服务计费规则运行。
  3. 点击开始演示，看到“演示数据”和演示角色后等待至少 2 秒，让主窗口建立基线。不要刚开始演示就连续点击事件按钮。
  4. 点击一次模拟升级，确认等级从 29→30（或从当前演示等级升一级），最近事件中只增加一条相应升级记录。允许演示回应时，等待角色给出简短祝贺，并明确这是演示/测试。
  5. 默认两次回应最小间隔为 20 秒。等上一次回应结束且间隔已过，再分别测试“模拟死亡”“模拟复活”“切换区域”。事件记录出现只代表已识别事件，不保证已经生成声音。
  6. 测试战斗免打扰：确保“战斗时免打扰”开启并已保存，切换到战斗状态后触发一次升级，再于 30 秒内切回非战斗，观察近期提醒是否在允许时机回应。超过 30 秒的事件会被丢弃；角色正在生成其他回复时，提醒也可能被跳过。
  7. 结束后点击返回真实画面采集，关闭“允许角色回应演示事件”并保存；若临时改变了冷却时间，恢复到 20 秒。确认页面重新等待或显示真实角色。

07 · 最终实机验收 · 在自己的正常游玩过程中完成

确认真实事件能到达精灵，并检查免打扰

  1. 先核对基线：关闭演示，保持真实角色在线至少 10 秒，确认等级、地图一致。初次连接或 /reload 后只有基线记录，不应因为“已经有这个等级”就祝贺一次。
  2. 先测容易触发的区域变化：步行跨到不同地图 ID 的相邻区域，保持网格持续可见，检查区域更新及事件。只走进同一地图内的小地名不一定有变化；带加载画面的传送可能重建基线，不用它作为第一次必达提醒测试。
  3. 测试游戏上下文：在 AIRI 聊天里问“我目前的等级和地图是什么？”；回答应与陪伴页显示的信息一致。若模型答错，保留当时的界面和回复供排查。
  4. 测试真实升级：用尚可升级的角色正常游玩，升级前让桥接保持在线，升级时不重载插件。观察等级自动变化、出现一条升级记录，并在静音关闭、冷却允许、角色空闲时收到回应。满级角色可先完成区域验收，把真实升级记为待测。
  5. 死亡/复活：在正常游玩自然发生时核对两种状态和事件；不用专门制造死亡。若开启战斗免打扰，应按战斗状态、冷却和 30 秒有效期判断是否有主动回应。
  6. 测试断流：先确认遥测开启，然后输入一次 /wowc telemetry 关闭，等 6 秒；状态应不再是实时在线。再输入一次恢复，等待重新在线。恢复只建立基线，不补播断流期间的升级。
  7. 测试静音：开启“游戏提醒静音”并保存，再正常切换区域。信息和事件仍应更新，但不主动发送新的游戏回应；已经开始播放的语音不一定被这个开关中断。测试完按自己的偏好保留设置。
