# 任务与练级助手：开发验证

日期：2026-11-01。对应五项计划中的第 4 项。

## 实现内容

- 两个游戏插件自动采集实际任务日志、目标进度、覆盖范围及截断状态，采用独立任务分片，不扩大主心跳。
- 明确区分目标列表覆盖、目标完成、可交付、客户端完成标记和本会话实际交付。删除或放弃任务不能推出已经完成。完成 API 的角色／账号范围未知。
- 设置增加“任务与练级”页面，支持当前日志、任务检索、分页和详情。游戏切换与角色变化隔离查询和结果。
- 无限服按等级、阵营、地区和关键词查询无限图鉴，展示任务链、接交对象、任务需求、风险和带来源的坐标。第三方临时资料逐项标注，缺失前置与坐标保持未知。
- 正式服只查询实际日志。已知等级按输入等级上下 3 级筛选，未知等级保留。任务日志分类不冒充地图地区，缺失阵营字段不能执行阵营过滤。本地六类 DB2 查询不能补造完整任务攻略。
- 聊天模型提供独立只读任务助手工具，与页面共用查询逻辑，显示结构化资料卡及相关网页。模型查询不改动页面筛选条件。
- 自动提醒默认关闭。手动开启后，全局 3 分钟冷却，同时遵守存活、非战斗、安静时段、静音、前台对话及已有调用预算。同一任务／建议去重，失败与取消保留尝试回执。
- 自动提醒仅根据实际日志生成就绪、交付、等级差及升级后的当前日志建议，不周期访问远程数据库。切角色、进入战斗、关闭开关、模型超时或观察过期会停止本次交互。
- 新任务修订分片暂时隐藏旧快照时保留当前角色的等级基线，避免漏掉战斗中或传输期间发生的升级。

## 真实免费查询

使用真实 MCP SDK 与同一个任务查询 runtime 完成列表和详情两次只读查询，没有递归请求整条任务链，没有调用个人模型或语音。

实际返回了 15 级部落、贫瘠之地条件下的任务候选，包括：[平原陆行鸟的威胁](https://wuxianwow.com/quest/844)、[野猪人的袭击](https://wuxianwow.com/quest/871)、[斑马的威胁](https://wuxianwow.com/quest/845)。任务 844 详情包含 12 步链、1 个接任务对象与 2 个位置记录。第三方字段保留临时标记，玩家进度仍为未知。

来源：无限图鉴 wuxianwow.com。采集证据：[真实 MCP 验证](logs/quest-assistant-live-verification.log)。本次未取得可验证构建号，因此没有补造版本。

## 交付边界

任务快照需要部署含 `Quests.lua` 的新版插件，并完全退出、重新启动游戏客户端。新版桥接也需要重启，受管连接最低版本为 2.18.0。

本轮没有实际运行游戏联调、个人模型或语音链路验收。旧 2.21.0 Windows 安装包与 ZIP 尚未重打包，不含本轮源码功能。没有 GitHub push 或关机。
