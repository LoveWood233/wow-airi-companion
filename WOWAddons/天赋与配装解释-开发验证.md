# 天赋与配装解释：开发验证

日期：2026-11-01。对应五项计划中的第 5 项。

## 已实现

- 两版插件只读采集实际提交天赋，包含角色／会话、职业／专精、配置、构建、语言、原始时间和明确的覆盖边界。
- 配置与待提交状态前后核对，并二次核对节点／提交条目。草稿、无法读取、受限或采集中变化时，不把预览当作已生效天赋。
- 节点、条目、定义、法术、树编号分别保留。页面位置与网站加点串顺序不能用来猜节点身份。
- 已投入点数、生效等级、方案投入及投入差分开。投入差按“方案投入−实际投入”计算，不把额外授予的生效等级当成可退点数。
- 未导出节点仍未知。只有实际读到零点的 `knownZeroNodes` 可表示零；截断和缺失均不会补零。
- 设置增加“天赋与配装解释”页面，支持节点／前置／关联技能解释、粘贴方案对照、19 槽穿戴观察及指定槽位的物品比较。
- 按用户单独确认的范围，接受已验证的无限图鉴天赋链接、数字加点串和明确的 JSON 节点清单。不猜正式服游戏导入码，不静默把清单中未列出的节点改成零点。
- 无限服查询无限图鉴，只有来源构建和实际观察构建一致才标精确映射。正式服使用实际观察与本地 DB2，不混入无限服机制。
- 装备比较要求明确槽位，区分戒指、饰品、主副手。部位匹配不代表满足职业、种族、等级或专精使用条件，双手切换和武器组合不暗中合计其他槽位。
- 保留穿戴实例链接、实际属性、提示文本和采集时间。新心跳不会刷新旧装备的采集日期；目录基础物品不冒充同一奖励词缀、附魔或插槽物品实例。
- 数值差用于解释已知取舍。缺失目录词条保持未知，明确空槽可以提供零贡献证据。正式服未解析的缩放字段不能当成平面属性，缺少数值时不生成精确收益。
- 已描述的触发条件和效果可以显示，触发率、套装是否生效、属性权重、DPS 与最优配装不作无证据推断。没有模拟、自动加点或自动换装。
- 聊天新增独立只读工具和资料卡，页面与模型各持独立查询客户端。来源、原查询时间、游戏观察时间和缓存提供时间分开。
- 当前天赋聊天上下文最多 24 KiB，保留全部选中等级，省略额外零节点／条目细节时明确标记。桥接请求挂起也会独立检查过期；已投入但生效等级为零／未知时，不发布其条目为生效技能。

## 粘贴格式

支持的例子：

```text
https://wuxianwow.com/talents/1?t=3&lv=15
3--
[{"nodeId":105958,"rank":3}]
```

网站串交给来源解析，只按其返回的节点 ID 与等级对照。链接职业必须与查询职业一致，首页和物品链接不能冒充天赋方案。来源裁剪／调整会显示变更，未列出的 JSON 节点保持未指定。

## 真实免费 MCP 验证

使用真实 SDK 和同一个查询 runtime 只读调用四项：天赋节点、网站方案、关联技能和物品效果。源构建为 `1.60.1.70707`，共 2 次 talents、1 次 spellbook、1 次 item_usage、1 次 stats。未提供角色观察时，当前等级、投入差和装备基准保持未知。

来源：无限图鉴 wuxianwow.com。核对页面：[战士天赋](https://wuxianwow.com/talents/1)、[强化英勇打击](https://wuxianwow.com/id/spell:12282)、[雷霆之怒，逐风者的祝福之剑](https://wuxianwow.com/item/19019)。证据：[公共 SDK 验证](logs/build-assistant-live-verification.log)。

另核对了[狮心头盔](https://wuxianwow.com/item/12640)的明确护甲数值，并加入真实夹具。来源评级词条若尚不能确认对应的实际属性键，会保留原标签，不编造差值。

## 交付边界

五项计划的源码功能已实现。本轮未执行实际游戏、个人模型或语音链路验收。没有部署插件、重打包既有 Windows 安装包／ZIP、GitHub push 或关机。

使用本项需要完整部署含 `Talents.lua` 的对应新版插件，完全退出并重启游戏，再重启新版桌面与桥接。受管采集最低桥接版本为 2.19.0。旧 2.21.0 安装包仍保留此前内容。

已完成永久挂起请求回归，过期等级不能无限保留在模型上下文；stop 后迟到结果也不能重建 writer。没有使用虚假 Pinia／Vue 或业务 store 替身。

shared、stage-ui、桌面和 i18n 定向类型检查通过：[shared](logs/build-shared-typecheck.log)、[stage-ui](logs/build-stage-ui-typecheck.log)、[desktop](logs/build-desktop-typecheck.log)、[i18n](logs/build-i18n-typecheck.log)。i18n 与桌面生产构建通过：[i18n build](logs/build-i18n-build.log)、[desktop build](logs/build-desktop-production.log)。

根目录 `pnpm lint` 通过，ESLint 为 0 errors、670 warnings：[lint](logs/build-root-lint-final.log)。最初唯一错误来自自动修改 fixture 时的临时路径清单，已由其创建者删除，最终检查通过。

根目录 `pnpm typecheck` 仍因既有 `scenarios-stage-tamagotchi-browser` 缺少 `vue-tsc` 退出 127，不能宣称全仓类型检查通过：[root types](logs/build-root-typecheck.log)。正式服既有本地化失败没有通过删除有效断言或改写另一服文案来掩盖。
