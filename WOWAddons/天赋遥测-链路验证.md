# 已提交天赋遥测：插件到桌面的链路验证

本记录覆盖第 5 项的双端实际天赋采集、独立分片、Python 拼装和桌面 TypeScript 契约。资料解释、方案对照、装备比较、页面／聊天卡由《天赋与配装解释-开发验证》汇总。不包含 DPS 模拟、自动配点或自动换装。

## 已实现

- 两版新增 `Talents.lua`，始终从 `C_ClassTalents.GetActiveConfigID` 读取实际活动配置，不取天赋界面的预览 config，不调用 Commit／Load／Stage／Refund／Purchase 等写 API。
- `active` 必须满足当前配置 ID、configInfo.ID／配置类型／树列表、职业与实际专精／客户端构建前后一致，`ConfigHasStagedChanges` 两次公开返回 false，节点 ID、rank、committed-entry 列表二次指纹也一致。Combat／CamelotCombat 指配置类型；角色战斗中 API 若可读仍可采集，不能把锁定或 secret 当有效读数。
- `staged`、`unknown`、`inaccessible` 均不供 selected nodes 或 known zeros；不会把未保存预览当已生效。trait 变更可中断未发完的旧 active，先传小型失效修订再采完整数据。版本、职业、专精和节点 ID 都保留各自来源，不按位序推算。
- 保留 `class` token 与独立 `classID`（UnitClass 第三公开值），`specID` 取 GetSpecializationInfo 返回的实际 ID，绝不是专精索引。GetBuildInfo 前两值无法组成完整版本＋build 时为 null；缺失或受限字段不补零。
- `treeID`、`nodeID`、`entryID`、`definitionID`、`spellID` 分离；投入 rank、active rank 与 activeEntry 的精确 rank 分开。配置 active 不等于每个已投入节点都在授予效果；非 activeEntry 的 rank 不按节点总数均摊。
- 可用性／可见性／边需求与原 API 条件公开值原样 nullable，条件 ID 不符即未知。`conditionsComplete` 只涉及节点 conditionIDs 的读取覆盖，不是所有条目、职业与解锁条件的充分证明；缺失条件不推导为已满足。
- `knownZeroNodes` 只在稳定配置下，两次实际读到 nodeInfo 的 activeRank 与 ranksPurchased 都为 0 时记录。未导出、secret、空／未加载树、截断或错构建不能推断未点；外部来源的展示树分组 ID 也不能冒充 trait tree ID。
- 独立 `traits` 分片，主心跳仍 v3；session／GUID／单调修订／采集和接收时间隔离。最多 8 树、128 selected nodes、每节点 8 entries 与 8 conditions、1024 known zeros，共享 64 KiB／274 帧，单块 240 字节，最多两份在途、20 分钟绝对期限，未来容忍 120 秒。
- 预算优先保留 selected，先截断 zero 并明确 partial，采用二分前缀避免逐项大 JSON 重编码。库存／任务／天赋公平分享首轮，装备后台保留时隙，新获取装备与比较仍优先。首轮完成后安静配置约 60 秒重采；较大负载可能超过业务 180 秒窗口，桌面必须显示陈旧／未知，不能篡改采集时间。
- 专精心跳短暂落后时隐藏天赋，待匹配后恢复，不把已校验的新修订永久拒绝。离线、暂停、演示、错误、错会话／角色和更新修订在途均不提供当前天赋。装备复用原 19 槽快照、完整实例链接、stats／tooltip 与覆盖标记，没有重做采集；该装备源没有固定周期重采，界面保留原采集时间。

## API 核实

无限服通过只读 `wuxianwow.addon_api` 核实 ClassTalents／Traits 函数、TraitConfigInfo、TraitNodeInfo、TraitEntryRankInfo、TraitEntryInfo、TraitDefinitionInfo、TraitCondInfo、TraitConfigType 和相关 trait 事件。UnitClass 被文档标为可能机密，采集逐返回值处理，第三字段不可读时 classID 为 null。来源：[无限图鉴 wuxianwow.com API](https://wuxianwow.com/api/)，[ConfigHasStagedChanges](https://wuxianwow.com/api/?q=C_Traits.ConfigHasStagedChanges#api)、[GetNodeInfo](https://wuxianwow.com/api/?q=C_Traits.GetNodeInfo#api)、[UnitClass](https://wuxianwow.com/api/?q=UnitClass#api)。

正式服参考 Blizzard 生成的 [SharedTraitsDocumentation.lua](https://github.com/Gethe/wow-ui-source/blob/live/Interface/AddOns/Blizzard_APIDocumentationGenerated/SharedTraitsDocumentation.lua) 与 [ClassTalentsDocumentation.lua](https://github.com/Gethe/wow-ui-source/blob/live/Interface/AddOns/Blizzard_APIDocumentationGenerated/ClassTalentsDocumentation.lua) 源码镜像。实际仍 feature-detect／pcall／secret-safe；不按旧经典树 API 或 UI 展示位序猜测。
