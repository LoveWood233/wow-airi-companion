## 使用

1. 先退出旧版应用，包括托盘中的进程。
2. 首次使用可运行安装包，或将便携 ZIP 完整解压后启动 `wow-companion.exe`。
3. “设置 → 安装与更新”可检查资源完整性、应用与桥接／双服插件版本、Python 及标准库。
4. Python 3.10 及以上单独安装，页面链接到 Python 官方 Windows 下载入口。当前桥接没有 pip 依赖。
5. 游戏内插件的实际安装版本，通过页面链接进入首次使用向导检查；点击安装／更新时先备份原插件。
6. 后续本地更新：将版本号更高、可信来源的便携 ZIP 解压到新目录，选择目录并查看完整校验后的版本和路径，再确认备份并启动。

默认用户目录沿用 `~/.airi-wow-companion`，`APP_USER_DATA_PATH` 显式指定时优先。
卸载保留用户资料，发行文件不含本机私密配置或桥接校准记录。
本包附带正式服插件 2.15.0、无限服插件 1.13.0、桥接 2.15.0、版本及完整性清单和 Windows 更新辅助程序。
可选 Godot 引擎未包含，现有网页角色渲染器保留。

## 更新与回退边界

- 不联网自动下载应用更新，不使用上游自动更新或发布接口。
- 更新前复用已实现的备份边界，保存人设、设置、游戏历史和聊天及附件的便携恢复副本，同时保存私有回滚日志。
- 恢复副本不包含服务密钥、登录状态、模型文件或发送队列。用户自行写入的文本保留。已有资产存储不做整个数据库镜像。
- 便携恢复副本沿用备份格式与 256 MiB 限制；备份失败就不启动更新，不关闭原应用。
- 新旧应用目录并排保留，完整文件清单校验拒绝缺失、篡改、额外文件、不兼容版本和非法路径。
- 关闭前调用与实际交接相同的辅助程序验证模式，检查路径祖先、用户目录、恢复任务冲突及任务标识。
- 最多等待原进程 60 秒退出，不强制终止原进程。新版须在 90 秒内完成服务注册、主界面挂载与路由就绪，且没有捕获的 Vue 错误，才能通过指定窗口回执确认。
- 新版启动失败时，只终止本次辅助程序创建的新版进程；启用原资料日志并启动旧版。必须收到旧版回执且恢复日志已完成清理，才记录回退成功。
- 若恢复有冲突或无法完成，保留恢复资料并显示需要处理，不能把未恢复的状态报成成功。
- 并排更新不改旧快捷方式。之后应从新版目录启动；需要本流程的升级不要直接覆盖旧目录。
- 断电或辅助程序被终止时，保留两个目录和恢复副本。便携副本仍可通过“备份与恢复”选择导入。
