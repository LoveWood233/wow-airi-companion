# 结构化资料回答：开发与验证记录

日期：2026-11-01。源码项目：`I:\GameTools\airi`。

## 已完成

陪伴精灵的聊天界面现在可以把真实的无限图鉴 MCP 返回结果展示为结构化资料卡。支持物品、配方、任务、NPC、副本、地图六类实体，以及 `search`、`fetch`、`item_usage`、`recipes`、`quests`、`npcs`、`instances`、`atlas` 查询。

- 资料卡显示名称、类型、实体 ID、已有属性和关联资料；材料用途可显示关联配方。
- 卡片明确标注「无限图鉴 wuxianwow.com」与《魔兽世界：无限》国服，并提供对应网页入口。
- 数据版本、快照生成时间、记录更新时间、价格采集时间、查询收到时间分别展示；缺失信息不补造，版本缺失显示未知。
- 临时来源、不完整资料、近似位置、截断列表保留提示。搜索摘要与详情分开，搜索命中不会直接当作完整详情。
- 完成的资料查询会自动展开一次；用户可以收起、展开关联内容、查看原始结果或手动重新运行。
- 加载、无匹配、调用失败和无效资料有独立状态。其他 MCP 服务器和不支持的工具保持原来的展示方式。
- 卡片由实际工具结果生成，展开卡片不会请求模型或补查数据库；保存的工具结果可用于重建卡片。

在无限图鉴明确公布 `stats` 工具时，适配器会读取并缓存可选版本证据。并发请求共用一次探测；成功缓存五分钟，失败退避三十秒，最长等待两秒。工具目录撤销 `stats` 后，旧请求不能重新写入版本缓存。仅开放 `search`、`fetch` 的验收连接不会收到额外调用。

## 使用方法

使用包含本次源码更改的陪伴精灵构建，连接可用的 wuxianwow MCP，并选择支持工具调用的模型。在聊天中提出资料问题，例如「查一下瑟银锭的资料和用途」。模型实际调用受支持的查询后，对应工具结果会自动显示资料卡。搜索结果可用于继续查询具体实体详情。

本功能继续使用已有的 MCP 配置与聊天入口，没有新增需要填写的密钥。它没有接通正式服本地 DB2；不能把无限图鉴结果作为正式服或怀旧服资料。
