## 使用

1. 退出旧进程，启动本次新构建，进入“设置 → 备份与恢复”。
2. 选择角色人设与偏好、游戏历史，可选聊天与附件，再导出本地 `.wowbackup.json`。
3. 恢复时先选择文件、查看校验后的时间、版本及清单，勾选恢复范围，再确认安排。
4. 可以取消待恢复任务，也可以点击“重启并恢复”。正常界面启动前会先保存恢复副本，再执行恢复。
5. 在同页查看最近结果，并点击“打开恢复副本文件夹”查看恢复前备份。

默认不导出服务密钥、登录状态、模型文件、MCP 私密配置和发送队列。用户自行写入的文本会保留。
备份没有加密，不应公开上传。格式版本 1，完整备份上限 256 MiB。

恢复会替换所选偏好和游戏历史。聊天会添加为本地副本，保留原会话，不恢复云端标识或任务状态。
恢复资料位于应用用户目录的 `companion-backups`。事务中断时，下次启动会按日志回滚。
若磁盘、权限或浏览器存储问题导致回滚无法完成，应用会停止正常启动并保留恢复资料。

## 执行命令

以下命令从仓库根目录执行。为避免包管理器自动安装无关工作区依赖，检查进程设置了临时环境变量：

```powershell
$env:pnpm_config_verify_deps_before_run = 'false'
pnpm -F @proj-airi/stage-tamagotchi exec vitest run --project node src/main/services/airi/wow-backup-repository.test.ts src/main/services/airi/wow-companion-gold.test.ts src/main/services/airi/wow-companion-level-history.test.ts src/main/services/airi/wow-companion-equipment-history.test.ts src/main/services/airi/wow-companion-equipment-comparisons.test.ts src/main/services/airi/wow-companion-loadouts.test.ts src/main/services/airi/wow-companion-profiles.test.ts
pnpm -F @proj-airi/stage-tamagotchi exec vitest run --project browser src/renderer/utils/wow-browser-backup.browser.test.ts src/renderer/pages/settings/wow-backup.browser.test.ts
pnpm -F @proj-airi/stage-tamagotchi typecheck
pnpm -F @proj-airi/i18n typecheck
pnpm -F @proj-airi/stage-tamagotchi build
pnpm typecheck
pnpm lint
```

共享 UI 类型检查直接在 `packages/stage-ui` 运行 `node_modules/.bin/vue-tsc.cmd --noEmit`。
i18n 在 `packages/i18n` 运行根目录 `node_modules/.bin/tsdown.cmd`，再执行上表类型检查。
