魔兽陪伴精灵使用说明

在魔兽世界中冒险时，让魔兽陪伴精灵了解你的角色、陪你聊天，并在升级、死亡或获得更好装备时作出回应。

适用于 Windows 版本。源码交付 2.16.0 · 桥接 2.12.0 · 正式服插件 2.12.0 · 无限服插件 1.9.0 · 说明更新于 2026 年 10 月 28 日。

开始使用 ↓详细安装与配置

查看角色坐标

更新正式服插件后，在游戏输入 /reload。打开 设置 → 魔兽世界正式服，角色信息中会显示当前地图坐标，例如“X 12.34，Y 56.78”。无限服使用对应版本页面。

插件每秒采样一次；移动后显示包含传输和轮询延迟。坐标只适用于同一张地图。副本、传送、离线或数据过期时显示未知，不会沿用旧坐标。单纯走动不会触发新的语音提醒。

保持传输码可见。坐标采用公开地图接口，部分场景无法读取。若始终未知，请核对插件、桥接和桌面端均已更新。完整实现与验收步骤。

切换语言

打开 设置 → 系统 → 通用 → 语言，选择中文、英文、西班牙语、法语、意大利语、葡萄牙语、日语、韩语等十二种语言。桌面界面、装备询问和固定闲聊文本随之切换，并保存语言选择。

游戏插件根据游戏客户端语言自动显示提示。更新插件后完整退出并重新进入游戏，载入新增的语言文件。语音模型需支持你选择的语言；角色与装备名称、自定义提示词和聊天历史保持原文。

魔兽模块和关键换装确认已人工复核；部分高级设置由本机模型补译，措辞可能需要进一步校对。查看适配范围与使用说明。

下载与安装其他魔兽插件

  1. 在桌面角色菜单打开“设置 → 魔兽插件中心”，点击右上角齿轮。
  2. 先申请 CurseForge API Key：打开 官方申请说明，填写申请表并等待审核邮件。详细申请步骤已列在实现说明中。
  3. 将获批密钥填入密码框并保存。随后分别为正式服、怀旧服和无限服选择已安装的客户端目录及对应游戏分支，再保存。
  4. 客户端目录应包含 Wow*.exe。正式服通常是 _retail_，怀旧服选择对应分支目录，无限服使用其实际客户端目录。
  5. 返回插件中心，选择大版本，通过分类、关键词和排序查找插件。选择兼容文件并点击安装，等待完成后在游戏中启用。

更新前退出游戏。同名旧插件若未由本模块管理，会提示先自行备份并移出；不会直接覆盖。更新备份保存在 C:\Users\10413\.airi-wow-companion\wow-addons-backups。拿到 API Key 后，需要你完成一次真实目录查询与下载安装验证。

01启动并连接游戏

  1. 在 I:\GameTools\WOWAddons 中双击 Start-WoWCompanion.cmd，等待魔兽陪伴精灵角色出现。魔兽陪伴精灵会管理桥接程序，无需另外手动启动。
  2. 启动魔兽世界正式服，在角色选择界面的“插件”中启用陪伴插件，再进入角色。
  3. 点击魔兽陪伴精灵角色边缘菜单的展开 → 魔兽世界信息卡，进入设置 → 魔兽世界正式服。开启“开启陪伴”，点击“保存陪伴偏好”。
  4. 页面显示自己的角色，并且状态为真实角色在线，即可开始使用。

展开菜单需要足够的窗口宽度。新版会在重启时将过窄的角色窗口自动加宽至至少 300 逻辑像素，完整显示三列按钮和魔兽世界信息卡入口。

游戏左上角的黑白方格是数据传输码。请让它完整可见，避免被窗口或其他界面遮挡；游戏最小化后无法持续读取画面。桥接采集间隔可设为 100 毫秒，减少新装备询问的等待。

装备祝贺和定时语音互动

获取符合提升规则的新装备后，魔兽陪伴精灵会称呼当前角色名，祝贺获得新装备、又能变强了，并保留属性取舍说明和换装询问。选择“好”后，请在游戏内点击“确认换装”。

连续非战斗满 1 分钟，魔兽陪伴精灵会主动进行一次简短语音互动，例如询问接下来想去哪里。战斗、死亡、离线、切换角色或静音会重新计时；已有聊天和装备询问优先。离线时间不会积累多次播报。

请先在当前魔兽陪伴精灵角色的“机体模块 → 发声”选好服务、模型与音色，开启魔兽陪伴并取消静音。互动直接调用语音服务，不需要额外聊天大模型请求。语音结束 3 秒后字幕气泡隐藏。

本轮更新后，从托盘正常退出魔兽陪伴精灵，再双击 Start-WoWCompanion.cmd。插件无需更新。若文字先出现但声音迟迟未出，可能仍在等待语音合成：本机实测一次 MiMo 请求约 59 秒后返回；程序最长等待 120 秒，装备提醒同时受游戏内提议期限限制。

模型配置保存在哪里

通过 Start-WoWCompanion.cmd 启动时，默认将模型、语音与角色记录保存到 %USERPROFILE%\.airi-wow-companion。正常模式与开发模式使用同一目录，避免 AppData 重定向造成配置分流。

配置成功后，正常退出、再从同一脚本启动即可沿用。本机已完成迁移，服务商、密钥和所选模型已恢复。其他已有安装首次切换目录前需先备份并迁移一致的数据；脚本遇到已有旧资料会提示，不会静默启动空配置。原目录与备份保留。需要自定义目录时，可通过 PowerShell 脚本的 -UserDataPath 参数指定。

让传输码少占屏幕

新版默认使用 64×64 物理像素，面积是原 128×128 的四分之一。首次加载时会自动缩小已有传输码，保留原来的位置；随后主动调大的尺寸会保留。

更新后，在游戏输入 /reload，并正常退出、重启魔兽陪伴精灵。可用 /wowc compact 切到最小尺寸，无限服使用 /wowf compact。

传输码需保持可见。若画面被拉伸而读取失败，检查游戏分辨率及“屏幕位置校准”；必要时使用 /wowc cell 2，并将每格像素设为 2。

当前穿戴装备与聊天

登录角色、新获得装备，以及换装或脱装后，插件会同步当前全身 19 个槽位。魔兽陪伴精灵按账号与角色保存最新快照，独立于仅保留 10 条的获取历史。

在“设置 → 魔兽世界正式服 → 当前穿戴装备”查看角色、更新时间和详情。全身资料需要后台分片传输，等收齐后，再问“我现在穿的装备是什么”“我的腿甲有什么属性”。

更新后，在游戏执行 /reload，并正常退出、重启魔兽陪伴精灵。保持传输码无遮挡。未知资料会明确标记；离线聊天引用的是最后保存的快照，不能代表此后发生的变化。

02首次配置对话与声音

在魔兽陪伴精灵设置的服务来源中配置你使用的平台。进入机体模块 → 意识选择聊天服务和默认模型；进入机体模块 → 发声选择语音合成服务、模型和声线。想对着角色说话，还需要配置语音识别并允许使用麦克风。

配置聊天模型后可与角色对话；配置语音后可朗读回复。角色信息、金币和等级记录不依赖模型。装备升级询问未配置语音时仍会显示文字气泡。

需要改变说话风格时，可编辑当前角色卡的“系统提示词”。提示词改变表达语气；声音由所选语音服务和音色决定。

03查看角色信息与记录

通过“魔兽世界信息卡”随时查看以下内容：

角色称呼：魔兽陪伴精灵会使用最新登录且有有效实时数据的角色名来称呼你，切换角色后自动更新。对话、游戏事件回应和装备气泡均使用这套称呼；数据失效时使用中性称呼，演示角色不覆盖真实角色。

内容怎样使用
角色状态查看角色等级、阵营、种族和所在区域。按喜好开启升级祝贺、区域回应、死亡及复活提醒。
金币账本按插件账号标识汇总已观察角色的金币收入、支出和净变化。首次余额只作起点；转账、邮寄等也算资金流动，因此不等同于纯收益。
等级历史各角色分别保存等级变化和每级耗时，采用现实时间，包含离线时段。首次记录或未接收数据时的升级会标记为部分记录或时间未知。
装备记录查看最近获取的装备及其属性，每个游戏版本共保留最近 10 条，超过后移除最旧记录。比较结果对应获取装备时的已装备物品。

04收到更好装备，确认后换上

  1. 获得新装备后，保持传输码可见，等待比较资料传到魔兽陪伴精灵。适合当前专精且属性无损提升时，会出现换装询问；有可用语音时同时播报。
  2. 装等和当前主属性都提高、但部分副属性下降时，也会询问。气泡列出提高与下降的数值，由你决定是否换上。例如“力量 +8，精通 -7”，不会保证伤害一定提高。
  3. 播报结束后，气泡显示“好” / “不用”。没有语音时直接显示选项。点击“不用”，或 10 秒内未选择，气泡关闭。
  4. 选择“好”后，返回游戏，在插件的换装提示中点击“确认换装”。游戏允许操作且检查通过后，才会更换装备。

桌面点击“好”之后仍需在游戏内确认。单纯装等更高不一定触发询问；未知属性、复杂特效、套装、附魔和插槽仍需自行比较。战斗等状态也可能暂时无法换装。

想重新检查背包里的装备时，在游戏输入 /wowc equip check。只检查某件装备可输入 /wowc equip check 257002，把数字换成对应物品 ID。无限服将命令前缀改为 /wowf。这会重新提出合适的候选，不会伪造一条新装备获取记录。

资料分片需要时间传完。常见 8 片比较资料与提议约需 7 秒，这是传输估算；实际等待还受采集质量、物品资料加载和队列影响。

05免打扰、字幕与退出

  • 游戏提醒静音：停止主动回应游戏事件，继续更新角色与统计。可另开“战斗时免打扰”，并调整提醒冷却时间。
  • 字幕气泡：普通语音字幕会在播报结束 3 秒后隐藏；装备询问按上面的 10 秒选择规则关闭。
  • 退出与重启：关闭设置页不影响陪伴。需要完整退出时，在 Windows 系统托盘中右键魔兽陪伴精灵图标，选择退出，再双击启动脚本。若提示 魔兽陪伴精灵已在运行，说明旧进程仍在运行。

06遇到问题时

现象处理方法
没有角色数据确认已进入游戏、开启陪伴，传输码没有遮挡。检查“屏幕位置校准”，使位置和单元格大小与实际画面一致；游戏中输入 /wowc status 可查看插件参数。若每格 1 像素时提示模糊，输入 /wowc cell 2，再把校准的“每格像素”设为 2。新版默认为 64×64 物理像素；可用 /wowc compact 切回最小尺寸。此前 X=8、Y=32 的坐标只适用于当时本机布局，其他窗口位置需自行匹配。窗口移动或换显示器后重新校准。
提示需要 v3同时使用配套的新版插件、桥接和魔兽陪伴精灵。更新插件后在游戏输入 /reload；仍有问题则完整重启游戏，并从托盘退出后重新启动魔兽陪伴精灵。查看详细步骤。
有文字没声音检查语音服务、模型和音色是否已选好，以及魔兽陪伴精灵、游戏提醒和系统音量是否静音。未配置语音时，装备询问仅显示文字属于正常行为。
没有装备询问先确认“真实角色在线”，将采集间隔设为 100 毫秒，并等待比较资料传完。正式服使用插件 2.10.1、桥接与魔兽陪伴精灵二开 2.11.1。更新后输入 /reload，并正常退出后重新启动魔兽陪伴精灵。输入 /wowc equip on 开启确认功能，再用 /wowc equip check 复查背包。新版允许装等和主属性都提高、仅副属性下降的合适候选发起询问。等级不足、专精不符、资料不完整或复杂效果仍需复核。登录时背包已有的装备不会自动补发获取询问。

本项目还提供独立的“魔兽世界：无限”设置页与插件包，需分别配置；当前仍待对应客户端实机验证。
