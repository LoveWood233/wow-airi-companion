### 无限服查询规则

涉及《魔兽世界：无限》国服的配方、物品、任务、副本、天赋和拍卖价格时，优先查询 wuxianwow MCP。转述时注明“无限图鉴 wuxianwow.com”并附对应网页。

工具不可用、记录缺失或数据范围不明时明确说明。不同游戏版本的数据不混用。拍卖挂单资料不当作实时成交价；结构化预算、价格监控和自动交易尚未实现。

接入说明：[无限图鉴 wuxianwow.com](https://wuxianwow.com/ai)。

### 结构化资料卡的使用与边界

- 普通聊天在实际收到支持的无限图鉴工具结果后，自动展开资料卡。支持 `search`、`fetch`、`item_usage`、`recipes`、`quests`、`npcs`、`instances`、`atlas`；其他 MCP 服务和未支持工具保持原有展示。
- 资料来自工具实际结果，自然语言回答保留；模型不能用自行编写的卡片数据替代查询证据。搜索摘要与具体实体详情分开，不把不同实体或版本混为一个结果。
- 每张资料卡注明“无限图鉴 wuxianwow.com”、无限服范围和对应网页。来源构建、快照时间、记录更新时间、价格采集时间与本次查询接收时间分开显示；缺少版本时显示未知。
- 临时第三方证据、近似位置、不完整资料和截断列表均显示提示；加载中、空结果、工具错误及无效数据分别处理。保留原始结果切换、手动折叠和重新运行。
- 展开卡片不追加实体查询。仅在实际开放 `stats` 时补充可选构建信息；受限验收入口仍只使用其允许的 `search`／`fetch`。正式服 DB2 未因此接入聊天。

需正常退出旧进程，运行最新本地构建后使用；已生成的 2.21.0 Windows 包不包含此功能。可在已配置无限图鉴与工具调用模型的聊天中询问“无限服瑟银锭有什么用”，检查资料卡、对应原文和角色回答。尚未进行个人模型、语音或真实游戏全链路验收，也未新增付费服务调用。

详见[结构化资料回答开发验证](/I:/GameTools/WOWAddons/结构化资料回答-开发验证.md)及[设计记录](/I:/GameTools/airi/docs/ai/adr/wow-structured-reference-answers.md)。

### 专业与备料的使用与边界

- 设置页新增“专业与备料”，支持从配方资料卡进入。按名称搜索真实配方，多条配方可合并材料；选择制作次数或已知产量对应的产物数量。
- 专业技能由用户填写，按起止技能区间生成路线、备料步骤及原料清单，复用中间产物。保留训练门槛、假设来源和概率升点估计。
- 自动读取当前无限服角色的随身背包，按物品 ID 合并数量；实时连接、角色／会话、新鲜度或读取错误不符合条件时不作为完整库存。
- 银行始终未知。部分采集的已知数量仅为下界，缺料显示上界。手填额外材料表示未包含在自动背包中的库存，与自动读数相加，不覆盖自动库存。
- 缺料预算由用户手动请求，标注挂单采集时间、服务器及阵营范围，提示缺价、过期与不同快照；不当作实时成交价或角色所属市场的保证。
- 本阶段优先无限服；正式服只读查询目前只覆盖六类实体，配方仍待整理，怀旧服不纳入。尚未采集完整专业与已学配方清单，也未做个人模型／语音／真实游戏验收。

### 正式服只读查询的使用与边界

- 设置“正式服本地资料”通过系统文件选择器选定本地 SQLite；直接查询不需要模型、联网、游戏运行或角色连接。路径仅显示在本地 UI，不交给模型。
- 支持物品、底层地图、世界地图、地区、技能／法术、副本首领六类。底层地图 0 合法，地图／世界地图 ID 不混用；正式服配方尚未整理。
- 原生工具 `builtIn_wowRetailQuery` 使用相同的只读查询与专用资料卡。没有新增 MCP 服务、软件依赖或模型调用配置，个人模型能否正确选择工具仍待实际验收。
- 查询模式使用已有 Python 桥接代码，独立固定本机端口 18767，按令牌和实例 ID 验证自己启动的子进程；不加载采集模块、窗口发现或采集配置，陪伴开关关闭仍可查询。
- 固定参数化 SQL、只读不可变连接、分页／超时／文本限制，不写源库、不创建索引。来源保留产品、构建、语言、真实导出时间、实际依赖表和数据集标识。
- 未叠加热修、加密分段、未知字段、法术原始模板与截断均有提示，不把客户端快照当成实时服务器资料，也不为本地记录编造网页链接。
- 无效选库不覆盖既有选择，清空选择停止自己的查询进程；旧查询不能在换库后冒充新数据。

桥接源码当前为 2.19.0，资源清单含 `retail_query.py`。真实只读数据库和 Node／Python 链路检查见[正式服只读查询开发验证](/I:/GameTools/WOWAddons/正式服只读查询-开发验证.md)。现有 Windows 安装包未重打包，本次未推送 GitHub；个人模型、语音与真实游戏验收仍未执行。

### 数据更新与缓存的使用与边界（2.31）

- 在“数据与缓存”页通过系统目录选择器设置游戏根和本地 CASC 工具目录。启动及每 5 分钟只读检查唯一活动正式服构建，发现变化仅提示；选中旧库时，新导出完成但尚未切换仍保留版本差异。
- 点击导出才运行本地 dotnet→CSV／SQLite→哈希／行数／integrity／八张表签名验证；阶段进度只显示真实计数。取消等待自己的直接子进程退出后再清理半成品。缺本地依赖或离线安全构建记录时直接报错，不 Git、不 restore、不下载 definitions、不联网热修或修复游戏。
- 验证成功后先查看构建、语言、来源与限制，再显式点击切换；已有验证快照可回滚。最多保留两个受管快照，当前使用的受管快照优先保留，再保留最新另一个；通过选库租约保护 active，持续切换时可暂缓清理。外部手选数据库、原 CASC 导出和无 marker 目录永不清理，链接目录被拒绝。
- 查询缓存按游戏、构建、来源、快照、连接与参数隔离，市场查询还区分服务器／阵营；静态资料 TTL 24 小时、拍卖采集快照 TTL 15 分钟。命中与来源接收／存入／过期时间分别展示，不能把采集价当实时成交价；换库、清空和重连拒绝旧在途结果。
- 缓存可查看占用、手动清空，过期清理与最近使用淘汰限制在 256 MiB；该上限不包括 SQLite 数据源、原始导出和受管快照。缓存故障回退真实查询。本地路径仅留在配置和 UI，不进入模型。
- 只有白名单只读工具、来源构建可验证且成功的资料可缓存；未知来源、错误、写入和其他工具绕过缓存。
- 若用户从其他资料页面手动选中暂存库，转换／取消清理也通过选库租约保护：转换提示 busy，保留文件与路径，不移动或删除当前所选库。
- 源构建、配置／索引、工具与 definitions 前后核对，保留未热修、加密与未知字段标记；大档案只检查文件代次，没有系统级快照，导出期间应暂停战网更新。完整真实游戏导出、个人模型、语音与游戏链路未验收。

开发检查见[数据更新与缓存开发验证](/I:/GameTools/WOWAddons/数据更新与缓存-开发验证.md)。本轮只更新本地源码，旧 2.21.0 安装包仍未重打包，本次无 GitHub push。

### 任务与练级助手的使用与边界（2.32）

- 在任务助手中选择版本、等级、阵营、地区／关键词，读取来源提供的任务目标、前后置、接交对象和坐标；页面与 `builtIn_wowQuestAssistant` 共用只读客户端，聊天提供来源卡。无限服来源为“无限图鉴 wuxianwow.com”及原文链接；第三方任务链／坐标标记“临时”，缺失不编造，不保证可接或最优路线。
- 正式服只显示匹配当前角色与会话的实际任务日志，不借用无限服资料。双端 `Quests.lua` 保留目标原文、已完成／所需数量及就绪状态，API 受限、折叠／隐藏、截断和陈旧快照明确未知。任务分片独立有界，不增加主心跳，不阻塞装备或库存，不操作游戏。
- 目标列表“完整读取”不代表目标完成；“可交付”不代表已交付。完成 API 标记的角色／账号范围未知；只有本会话 `QUEST_TURNED_IN` 可作为实际交付证据，移除不推断完成，截断记录缺席不推断未完成。
- 主动任务提醒默认关闭；打开后可提醒就绪、会话交付、较高任务等级或新升级后的日志选项。全局 180 秒最多尝试一次，跨游戏、角色与重启保存回执，失败／取消也占冷却；使用现有生成预算并遵守安静时段、战斗、死亡、静音和忙碌规则。
- 自动提醒仅解释观测事实，不后台查 MCP、截图、读其他版本攻略或控制游戏。切角色／人格／模型／语言、失去资格、超时或睡眠会丢弃迟到文本并停止自己启动的音频。较高任务等级只是风险提示，不等于准入限制、必死或最优路线。

### 天赋与配装解释的使用与边界（2.33）

- 使用天赋与配装页面或 `builtIn_wowBuildAssistant` 查看实际已提交天赋、指定技能／节点、粘贴方案与某个明确装备槽的比较；页面和工具共用只读客户端，聊天提供来源卡，模型不会改写页面表单或游戏配置。
- 双端 `Talents.lua` 从活动配置读取，前后无 staged 且配置／职业／专精／构建及节点 ID／rank／committed-entry 指纹稳定才 active；编辑中、受限或不稳定时不输出实际 rank，不把预览当生效。ID、投入与 active rank 分开；knownZero 只来自真实两次零值，缺席／截断／secret 不归零。
- 无限服注明“无限图鉴 wuxianwow.com”并附链接，同构建才精确映射；正式服只用当前遥测和本地 DB2。来源展示树、node、entry、definition、spell ID 不互换，职业与专精不靠索引猜，无法核实就明确未知。
- 可粘贴明确 nodeId／rank JSON 或来源支持的无限图鉴方案；规范化、校验／调整与未知前置单列。没有解码正式服导入码、不猜位序、不把缺席节点清零，也不自动应用方案。
- 装备复用原 19 槽快照，必须指定槽位，保留实际 itemGUID、完整 bonus／实例链接、stats／tooltip 和原采集时间。基础图鉴物品不等于实际实例，正式服缩放字段不当最终平铺属性；双手／双持、戒指／饰品不能偷偷合并或清除另一槽。
- 输出观测事实与条件解释，不给 DPS／权重／最佳保证，不模拟、不自动换装或控制游戏。资料缺失、版本不符、陈旧天赋与不完整装备均保持未知；完整宝石／附魔／套装联动、模拟和优化另列扩展。

源码组件为桥接 2.19.0、正式服插件 2.19.0、无限服插件 1.17.0，采集最低要求桥接 2.19。使用前完整部署包含 TOC／Talents.lua 的插件并完整重启游戏，再重启最新桌面与桥接。检查见[天赋与配装解释开发验证](/I:/GameTools/WOWAddons/天赋与配装解释-开发验证.md)及[天赋遥测链路验证](/I:/GameTools/WOWAddons/天赋遥测-链路验证.md)。未做真实模型／语音／游戏验收，旧 Windows 安装包未重打包，本次无 push。
