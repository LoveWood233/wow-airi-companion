# Local companion product identity

Status: Accepted

Date: 2026-10-27

The desktop product uses the display name 魔兽陪伴精灵.
Window titles, tray labels, onboarding, settings, chat fallbacks, and supported locale values use this name.
The About page shows the companion version and project link.
The desktop no longer offers upstream account, credits, subscription, or hosted-provider entry points.
Direct account routes return to local settings before they mount.
Onboarding configures local provider selections without application sign-in.

Existing model credentials, character cards, chat history, and game records remain in the same profile.
Package identifiers, transport fields, saved window identities, and storage keys remain stable.
These identifiers are runtime contracts, not display branding.
Third-party copyright notices and license files remain in source and distribution files.

Upstream automatic updates and product analytics startup are disabled for this fork.
Model and speech services selected by the user remain available.
Local diagnostic recording retains its existing controls.
