# Warcraft settings product name

Status: Accepted

Date: 2026-10-26

The Retail and Forever settings use the product name 魔兽陪伴精灵 in their display text.

Both pages share the `wow-companion` locale namespace. Its English and Simplified Chinese messages use the requested name.

Visible bridge and storage errors use the same product name.

The application keeps its existing package names, storage paths, and internal identifiers.
