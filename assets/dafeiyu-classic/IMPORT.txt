大肥鱼 × 经典八职业 — 120 动作 / 60 fps / v0.4.0 修复候选版

当前状态
这是覆盖八职业全部120个动作的修复候选版，尚未通过全量视觉验收。
目标共960段640×360透明VP9 WebM，无音轨；原114动作名和6个新增动作接口不变。
本轮已修订部分装备姿态图源，并调整运动制作方式。
本轮修订78张姿态图集，候选960段共557760帧、2810234552字节；当前哈希和技术核验记录见仓库verification/v040/。
实际视频仍发现舞狮头/堆雪人/落叶动作重叠手臂或道具、小憩起卧手部残影、跑步接缝等问题。
部分源姿态之间仍有装备细纹变化，不能声称本版所有装备无漂移或所有关节连贯。

制作方法
八职业各10条动作使用固定母版，共80条：
待机呼吸休闲、碎碎念-对屏碎碎念、工作状态-雀跃庆祝、开心蹦跳、点击回应-开心跃动，
以及害怕、害羞、难过（眼睛饱含泪水）、想去玩（期待星星眼）、大哭。
其中79条由通用职业固定母版工具处理，战士开心蹦跳保留v0.3.2原固定母版分支。
开心蹦跳为8秒；点击回应-开心跃动为独立10秒三次跃动，沿用各自动作名。
身体与装备采样同一母版纹理，武器随挂点运动；表情限定在脸内区域。
80段实际视频共1340帧人工样本中装备/双臂一致，但脸内切换叠影仍未消除，不等于整段视觉通过。
其余880条默认用RIFE4.26处理预乘RGBA；这是插帧方法，不保证姿态对应、装备细纹或肢体解剖正确。
小憩已加入完整起卧桥接，但仍有未通过的实际中间帧。
60fps是输出采样率，含静止保持、算法中间帧和网格采样帧，不表示每秒60张独立绘画。
本包是按动作语义制作的职业资源，并非原始114段视频的逐帧等同换装。

导入步骤
1. 完整解压候选ZIP，不要直接将ZIP作为角色目录选择。
2. 在AIRI的大肥鱼资源包导入入口，选择packs下某一个职业文件夹。
   所选文件夹内必须直接包含pack.json和120个.webm文件。
3. 按需分别导入八职业，选择名称含“120动作 60fps v0.4.0”的角色包。
4. 导入后仍按候选版检查具体动作；能导入或播放不等于已经通过全量视觉验收。

观看与重建
可从 GitHub Release 下载完整 WebM 资产包，参见仓库 DOWNLOAD.md。
https://github.com/LoveWood233/wow-airi-companion/releases/tag/dafeiyu-assets-v0.4.0-candidate
也可按README重建，职业包位于build/packs/。
本轮制作环境为Python3.12、tools/requirements-rife.txt固定依赖、Node.js24+和带libvpx-vp9的FFmpeg/ffprobe。
先运行tools/download-rife.py，脚本按tools/rife_v426/UPSTREAM.json下载固定版本模型，并校验压缩包与权重SHA256。
默认权重位于build/models/rife-v4.26/flownet.pkl；渲染会再次校验哈希。
RIFE只用于离线制作；导入已有WebM不需要安装Python或模型。
tools/package.py生成的ZIP含职业pack.json、120个WebM及IMPORT.txt/ATTRIBUTION.txt。
提示词、源图、工具、预览与验证记录留在Git仓库中，不包含在该ZIP内。
