# v0.1 八职业动画源图（历史素材）

这里保留早期动作预览的八张原始透明 PNG 图集。每张是 4×4、16 格的姿态源图；八职业当时各导出三个动作，共 24 段：待机呼吸休闲、碎碎念-对屏碎碎念、工作状态-雀跃庆祝。

这些图属于 v0.1 历史版本，用于保存设计与生成来源，不代表 v0.4.0 已通过装备一致性或动作连续性验收。现有完整动画需使用对应版本的媒体包；本目录只有源图与生成记录，不能单独作为 AIRI 动画资源包导入。

八张 PNG 按原字节复制，没有重新绘制、裁切或编码。`source-provenance.json` 逐一记录历史相对路径、原始与副本 SHA256，以及两个生成 JSON 修改前后的 SHA256。

`generated-sources.json` 和 `generation-prompts.json` 保留原提示词与角色描述。本机用户目录和图像生成缓存的绝对路径已改为本目录文件引用，并以 `source_generation_file` 保留原生成文件名；角色参考指向 [初版八职业设计图](../../static-v01/)。`original_reference` 保留原历史相对路径，便于核对生成链。

角色基础、动作参考及许可的归属链见 [ATTRIBUTION.txt](../../../../ATTRIBUTION.txt)。本补存不会更改或替代其中的署名和授权说明。
