# 工具健壮性修订静态复核

日期为 2026-11-14。本次修订对应 PR #3 静态审查发现的六项问题，基线为 `a16ab05f2d9aa8753473f6b7ccde8582d615eda4`。

| 问题 | 代码修订 |
| --- | --- |
| Windows 默认编码影响中文配置与预览 | 相关生产工具的文本读写显式指定 UTF-8 |
| 解码错误日志积满导致审计阻塞 | stderr 写独立临时文件，解码 watchdog 到期终止进程，探测及回收有超时 |
| 审计输出覆盖输入渲染记录 | 任何输出创建前检查与媒体、渲染记录、源文件、工具目录的重叠，包含符号链接别名；直接调用单项审计也检查 |
| 并发生成覆盖同名临时视频 | 输出目录及单动作互斥锁，独占临时视频，完成后原子替换，孤儿工作进程拒绝发布；预览页也使用独占临时文件 |
| 重建部分失败仍能交付新旧混合包 | 首次写媒体前撤销旧清单并写未完成标记；完整职业成功才恢复清单，失败和部分生成不恢复；打包和审计拒绝带标记目录 |
| 全量审计漏动作或零输入却正常完成 | 按提交的动作计划与职业清单核对选中职业各 120 段和对应记录，未知职业或缺失输入立即失败，摘要明确全量或整职业局部范围 |

静态复核覆盖异常处理、锁的生命周期、临时文件清理、失败后恢复和跨工具的输入输出约定。补写回归测试源码，覆盖编码、并发交错、发布失败、未完成目录、缺失输入、路径重叠和解码进程回收。

按用户明确要求，本次没有运行任何测试、类型检查、编译、资产生成、FFmpeg 解码、浏览器预览或 AIRI 导入。只读取代码并检查 Git 差异及空白格式。上述测试源码尚未执行，不能视为测试通过。

源图、WebM、Release 附件和历史验证结果未重新生成。v0.4.0 仍为视觉验收未通过的候选版本；本次工具修复不改变该状态。再次重建会因工具指纹改变而使旧渲染缓存失效。

恢复生成时，应结束旧版本进程，并在同一输出目录完整重跑受影响职业。新工具之间通过持久锁文件协调；锁在进程退出后由系统释放，不要删除使用中的锁文件，也不要手动清除未完成标记。
