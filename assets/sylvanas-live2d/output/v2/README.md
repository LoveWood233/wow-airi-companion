## 使用

重新导入并选中 v2 模型卡片，开启“启用鼠标跟踪”和“启用眨眼”，将“眨眼模式”设为“自动”。空闲动画选择 `Idle`。

Idle 每 48 秒循环，包含四秒呼吸周期、普通眨眼和第 35–40.2 秒的一次哈欠。`Yawn` 是独立的 5.2 秒动作，空闲选择器会重播它，不作为长期待机。

旧安装版已支持方向跟随与本包内置动作。平滑归中和强制眨眼叠加的修复属于应用代码，需更新应用才能取得，更新 ZIP 不会替换应用程序。

哈欠结束后嘴参数精确为 0，闭嘴层不透明度为 1，张嘴层为 0。检查按项目实现关闭 SDK 默认呼吸，并实际运行生产强制眨眼插件。
