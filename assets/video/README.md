# 职业专属动画

开启陪伴连接后，主桌宠窗口根据传输码中的当前在线角色职业切换整套动画。待机、点击、拖拽、说话、思考和睡眠均使用所选职业的动作。

每个职业的一套动画放在单独目录。目录可以使用英文职业名，或以中文职业名开头。

```text
assets/video/
  牧师/
    待机呼吸休闲_00001.mp4
    点击回应-元气挥手_00001.mp4
    ...
  mage/
    待机呼吸休闲_00001.mp4
    点击回应-元气挥手_00001.mp4
    ...
```

文件名使用内置动作名，支持 ComfyUI 的数字后缀，例如 `_00001`。每段职业动画支持最大 32 MiB 的 MP4 或 WebM，配套 PNG 可留作预览。

一套目录包含 114 个动作。程序按动作名识别 11 个基础交互和移动动作、80 个随机动作、15 个事件动作、3 个睡眠动作和 5 个吃白饭动作。各职业可沿用同一套 ComfyUI 输出命名。完整分类及牧师视频见[动作分类](./动作分类.md)。

角色登录或切换时立即查找该职业素材。当前职业的素材每 30 秒重新检查一次，生成完整后自动载入。多个完整目录中使用最近更新的一套，仍在写入的 MP4 会等待完成。

如果进游戏后才首次打开陪伴连接，传输码可能已经发完登录资料。此时在游戏中输入 `/reload`，就能重新发送当前角色的职业。

职业素材尚未齐全时继续显示当前形象。用户手动选择形象后，会使用手选结果，下一次角色登录或职业变化时重新跟随角色职业。

从项目内运行时，程序优先读取本目录。安装包还会携带打包时的职业动画，供项目目录之外的安装版读取。

MP4 按原始画面播放。当前牧师素材带不透明黑色背景。透明 WebM 会保留透明通道。

## 游戏状态与动作

| 触发条件 | 播放行为 |
| --- | --- |
| 主桌宠空闲，角色未处于离开状态 | 从“小动作、玩耍、吃什么、时节、文字”五类共 80 个动作中按分类权重随机播放。每段结束后重新抽取，有其他可播动作时避开上一段。 |
| 陪伴精灵正在思考 | 从当前形象的 6 个工作状态动作中随机选择。思考持续时继续随机播放，避开刚播过的动作。 |
| 当前角色进入离开状态 | 播放一次“睡觉-开始”，随后保持“睡觉-循环”。同一角色明确退出离开状态时，播放一次“睡觉-起来”。 |
| 当前角色身上出现营火增益 | 从“开心小跑”和“侧身急躁跑”中选一个，再依次播放“期待开饭”“吃饭·碗饭”“吃饭团”。增益持续时用另一种小跑开始下一轮，消失后退出玩法。 |

离开状态优先于思考、说话和营火。醒来后，精灵会根据当时的状态选择下一段动作。换角或连接失效时会清理上一位角色的游戏活动。
